# Receipt Recorder

Simple app to record restaurant receipts.

## Local Development

### Backend
```bash
cd backend
npm install
npm run dev
# API runs at http://localhost:3001
```

### Frontend
```bash
cd frontend
npm install
npm run dev
# App runs at http://localhost:5173
```

## Deployment

- **Frontend**: Deploy `frontend/` to [Vercel](https://vercel.com) (free)
- **Backend**: Deploy `backend/` to [Render](https://render.com) (free)

See `implementation_plan.md` for full deployment instructions.
